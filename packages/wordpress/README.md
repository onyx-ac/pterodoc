# @pterodocs/wordpress

The WordPress REST target for [pterodocs](https://github.com/onyx-ac/pterodocs): pages
identified by parent and slug, media keyed by content hash, and pruning that trashes
rather than deletes.

You probably want the [`pterodocs`](https://www.npmjs.com/package/pterodocs) package
instead.

The documentation for all of pterodocs is at <https://onyx.ac/products/pterodocs/docs/>.
